Окей, вот ручное выполнение первых двух итераций метода половинного деления для функции  *f(x) = x³ + 3x² − 24x + 1*  на интервале *L = [1; 3]*  с *ɛ = 0.2*:

**Итерация 1: k = 0**

1.  **Шаг 1: Задаем начальные значения:**
    *   a₀ = 1
    *   b₀ = 3
    *   ε = 0.2
	
2.  **Шаг 2: k = 0**

3.  **Шаг 3: Вычисляем среднюю точку:**

    *   x₀ᶜ = (a₀ + b₀) / 2 = (1 + 3) / 2 = 2
    *   L₂₀ = b₀ - a₀ = 3 - 1 = 2
    *   f(x₀ᶜ) = f(2) = 2³ + 3(2)² − 24(2) + 1 = 8 + 12 − 48 + 1 = -27
	
4.  **Шаг 4: Вычисляем y₀ и z₀:**
    *   y₀ = a₀ + |L₂₀| / 4 = 1 + 2 / 4 = 1.5
    *   z₀ = b₀ - |L₂₀| / 4 = 3 - 2 / 4 = 2.5
    *   f(y₀) = f(1.5) = (1.5)³ + 3(1.5)² − 24(1.5) + 1 = 3.375 + 6.75 - 36 + 1 = -24.875
    *   f(z₀) = f(2.5) = (2.5)³ + 3(2.5)² − 24(2.5) + 1 = 15.625 + 18.75 - 60 + 1 = -24.625
	
5.  **Шаг 5: Сравниваем f(y₀) и f(x₀ᶜ):**
    *   f(y₀) = -24.875
    *   f(x₀ᶜ) = -27
    *   f(y₀) > f(x₀ᶜ)  (так как -24.875 > -27)  =>  Переходим к Шагу 6.
	
6.  **Шаг 6: Сравниваем f(z₀) и f(x₀ᶜ):**
    *   f(z₀) = -24.625
    *   f(x₀ᶜ) = -27
    *   f(z₀) > f(x₀ᶜ)  (так как -24.625 > -27)  =>  Исключаем интервалы [a₀, y₀) и (z₀, b₀], a₁ = y₀, b₁ = z₀.
    *   a₁ = 1.5
    *   b₁ = 2.5
	
7.  **Шаг 7: Вычисляем L₂₁ и проверяем условие окончания:**
    *   L₂₁ = |b₁ - a₁| = |2.5 - 1.5| = 1
    *   L₂₁ > ε  (так как 1 > 0.2)  => k+=1 => Продолжаем.
	
**Итерация 2: k = 1**

8.  **Шаг 3: Вычисляем среднюю точку:**
	*	x₁ᶜ = (a₁ + b₁) / 2 = (1.5 + 2.5) / 2 = 2
	*	L₂₂ = b₁ - a₁ = 2.5 - 1.5 = 1
	*	f(x₁ᶜ) = f(2) = 2³ + 3(2)² − 24(2) + 1 = 8 + 12 − 48 + 1 = -27

	**Шаг 4: Вычисляем y₁ и z₁:**
	*	y₁ = a₁ + |L₂₂| / 4 = 1.5 + 1 / 4 = 1.75
	*	z₁ = b₁ - |L₂₂| / 4 = 2.5 - 1 / 4 = 2.25
	*	f(y₁) = f(1.75) = (1.75)³ + 3(1.75)² − 24(1.75) + 1 = 5.359375 + 9.1875 - 42 + 1 = -26.453125
	*	f(z₁) = f(2.25) = (2.25)³ + 3(2.25)² − 24(2.25) + 1 = 11.390625 + 15.1875 - 54 + 1 = -26.421875

	**Шаг 5: Сравниваем f(y₁) и f(x₁ᶜ):
	*	f(y₁) = -26.453125
	*	f(x₁ᶜ) = -27
	*	f(y₁) > f(x₁ᶜ) (так как -26.453125 > -27) => Переходим к Шагу 6.

	**Шаг 6: Сравниваем f(z₁) и f(x₁ᶜ):**
	*	f(z₁) = -26.421875
	*	f(x₁ᶜ) = -27
	*	f(z₁) > f(x₁ᶜ) (так как -26.421875 > -27) => Исключаем интервалы [a₁, y₁) и (z₁, b₁], полагаем a₂ = y₁, b₂ = z₁.
	*	a₂ = 1.75
	*	b₂ = 2.25

	**Шаг 7: Вычисляем L₂₃ и проверяем условие окончания:**
	*	L₂₃ = |b₂ - a₂| = |2.25 - 1.75| = 0.5
	*	L₂₃ > ε? 0.5 > 0.2? Нет.
	*	k = k + 1 = 2
